# Feature Test Assignment

## 1. Setup Applications
### Install dependency
npm i
composer install

### Generate App key
php artisan key:generate

### Setup database & env
Copy and rename .env.example to .env -> fill the APP_URL, DB_CONNECTION, DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME, DB_PASSWORD with your preferences

### Migrate database
php artisan migrate

### Initial runing 
npm run dev
php artisan serve
